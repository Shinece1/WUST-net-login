# 校园网自动认证工具 —— 使用指南

一个不用每次手动登录校园网的小工具：**双击 → 自动检测 → 没联网就自动认证 → 告诉你结果**。

- 绿色免安装，不写注册表，不需要装任何运行库（Windows 10 / 11 系统自带所需组件）
- 你的学号密码**只存在你自己电脑上的一个文件里**，程序本身不含任何人的账号，不会上传
- 支持 Windows 10 / 11；Windows 7 / 8 极少数老系统可能需要先装系统的「通用 C 运行库」更新
  （KB2999226），装不上就用同目录的 `wust-auth.exe` 在新一点的电脑上跑

---

## 一、第一次使用（约 1 分钟）

1. **解压到一个固定目录**，例如 `D:\wust-auth\`
   （别放桌面或下载文件夹，容易误删；也不建议放 `C:\` 根目录和 `Program Files`，那里普通用户写不进配置）
2. **双击 `wust-auth.exe`**
3. 按提示输入**你自己的**学号和密码：

```
未检测到可用的账号配置，请先录入你的学号和密码。
请输入学号：2023xxxxxxxx
请输入密码：                 ← 输入时不显示字符，这是正常的，输完直接回车
配置已保存到：D:\wust-auth\wust_config.ini
```

4. 出现菜单后，输入 `1` 回车，等待结果：

```
[1/3] 正在检测网络是否已经连通 ...
      当前未联网，开始认证。
[2/3] 正在向认证服务器提交登录请求（学号 2023xxxxxxxx）...
      登录成功！
[3/3] 正在复检网络连通性 ...
      网络已连通，可以正常上网。
```

看到 **「网络已连通，可以正常上网」** 就成功了。
如果本来就已联网，它会直接告诉你「当前网络已经连通（已在线），无需重复认证」，不会重复发请求。

---

## 二、以后怎么用

双击 `wust-auth.exe` → 输入 `1` → 完事。

菜单里三个选项：

| 输入 | 作用 |
| --- | --- |
| `1` | 自动检测网络并登录（平时用这个） |
| `2` | 修改学号或密码（只想改密码就学号直接回车） |
| `3` | 退出 |

> 小知识：如果开机后已经能上网，跑一次选 `1` 也会自动跳过认证，不会有副作用。

## 三、想开机自动登录？（可选）

程序目录里有个 **`wust-authw.exe`**，它是专门给开机自启用的**静默版**——不弹任何窗口。

**注意：双击它什么都不会显示**，这是正常的（它在后台跑一次就退出）。

打开「命令提示符」（按 `Win+R` → 输入 `cmd` → 回车），把下面命令里的路径换成**你自己的**解压路径，然后执行：

```bat
schtasks /create /tn "校园网自动登录" /tr "D:\wust-auth\wust-authw.exe" /sc onlogon /delay 0000:30 /f
```

这样就装好了：每次登录 Windows 后等 30 秒，它会自动认证一次。

**怎么确认它真的跑了？** 打开程序目录下的 `wust-auth.log`（记事本打开），每次运行都会留一段记录：

```
===== 2026-10-19 18:17:46 | wust-auth v1.2 | 静默启动（开机自启） =====
...
===== 2026-10-19 18:17:49 | 结束：已在线或登录成功（退出码 0）=====
```

- **不想开机自启了**：`schtasks /delete /tn "校园网自动登录" /f`
- **想断网自动重连**：再加一条每 10 分钟检查一次的任务
  `schtasks /create /tn "校园网自动登录-保活" /tr "D:\wust-auth\wust-authw.exe" /sc minute /mo 10 /f`
- 要用「任务计划程序」图形界面配置的话：程序填 `wust-authw.exe`，**参数留空**，触发器选「登录时」。

## 四、常见问题

| 现象 | 怎么办 |
| --- | --- |
| 第一次运行时弹出「Windows 已保护你的电脑」 | 这是对**未签名程序**的常规提示（软件没有买数字签名证书）。点「更多信息」→「仍要运行」即可；如果是从网上传过来的，也可以右键文件 →「属性」→ 勾选「解除锁定」→ 确定 |
| 双击 `wust-auth.exe` 窗口一闪就没了 | 开 `cmd`，`cd /d D:\wust-auth` 然后执行 `wust-auth.exe`，就能看到完整输出和报错 |
| 双击 `wust-authw.exe` 完全没反应 | 正常，它是静默版；要交互请用 `wust-auth.exe`，想看结果看 `wust-auth.log` |
| 提示「账号或密码不正确」 | 选菜单 `2` 重新输入密码，注意大小写；确认账号没被锁定 |
| 提示「连不上认证服务器」 | 先连上校园 WiFi 或插上网线再运行 |
| 中文是乱码 | 先在 `cmd` 里执行 `chcp 65001` 再运行；或者用 Windows Terminal |
| 提示配置保存在 `AppData` 里 | 说明程序目录不可写，程序自动把配置存到了 `%APPDATA%\wust-auth\`，能正常用；想放到程序旁边就把程序换个目录重新录入 |
| 想确认它读的哪个配置 | 执行 `wust-auth.exe -p`，会列出配置文件路径和读取结果 |
| 提示“已在线”但其实上不了网 | 用 `wust-auth.exe -a -v` 看探测判定依据；必要时换个探测地址，见下 |

<details>
<summary>进阶：换探测地址 / 换认证服务器（一般用不到）</summary>

百度偶尔打不开但别的网站正常时，可以把探测地址换成 bing：

```bat
set WUST_PROBE_URL=http://www.bing.com
wust-auth.exe -a -v
```

如果换的地址返回的是 `200` 页面（而不是跳转），可能还要告诉程序“页面里必有的字样”，
否则它会保守地判成未联网：

```bat
set WUST_PROBE_MARKER=bing
```

校园网换了认证服务器地址时（用浏览器 F12 抓包确认）：

```bat
set WUST_LOGIN_URL=http://新地址/api/account/login
wust-auth.exe -a -v
```

</details>

## 五、安全提醒

- 配置文件名是 `wust_config.ini`，里面是**明文密码**。
  **不要发给别人、不要传到网盘或群文件**——包括你同学之间，各人用各人的。
- 程序只做两件事：检测网络时访问 `http://www.baidu.com`；认证时把学号密码
  POST 给学校认证服务器 `http://59.68.177.9/api/account/login`。
  除此之外不联网、不上传任何东西，跑完就退出，没有后台常驻进程。
- 换电脑或重装系统后，重新双击 `wust-auth.exe` 录入一次即可。

## 附：两个 exe 的区别

| 文件 | 用途 | 会不会有窗口 |
| --- | --- | --- |
| `wust-auth.exe` | 手动使用：录入、改密码、登录 | 有（控制台） |
| `wust-authw.exe` | 开机自启用：后台静默自动登录 | **没有** |

Linux 用户：`make` 编译出 `wust-auth`，用法同上（`./wust-auth` 交互、`./wust-auth -a` 静默），
